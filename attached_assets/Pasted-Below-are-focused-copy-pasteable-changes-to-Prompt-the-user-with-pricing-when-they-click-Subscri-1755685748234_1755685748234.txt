Below are focused, copy-pasteable changes to:
- Prompt the user with pricing when they click Subscribe.
- On confirm, subscribe and immediately reflect it in:
  - My Subscriptions (/my-subscriptions)
  - Billing (/billing)

This is done fully client-side for instant UX using a tiny local storage helper, while still calling your existing POST /api/ai-models/:id/subscribe endpoint. If/when you persist subscriptions server-side, the UI will still work; we also invalidate related queries.

New shared helper

```typescript name=client/src/lib/subscriptionsLocal.ts
const STORE_KEY = 'gefi.local.subscriptions';

export type LocalSubscription = {
  id: string; // local id
  modelId: number | string;
  modelName: string;
  developerName?: string;
  price: number;
  billingCycle: 'monthly' | 'annually';
  status: 'active' | 'paused' | 'trial' | 'cancelled';
  subscribedDate: string;
  nextBilling?: string | null;
  category?: string;
  performance?: string; // purely cosmetic
};

function read(): LocalSubscription[] {
  try {
    const raw = localStorage.getItem(STORE_KEY);
    return raw ? JSON.parse(raw) : [];
  } catch {
    return [];
  }
}

function write(items: LocalSubscription[]) {
  try {
    localStorage.setItem(STORE_KEY, JSON.stringify(items));
  } catch {
    // ignore
  }
}

export function getLocalSubscriptions(): LocalSubscription[] {
  return read();
}

export function addLocalSubscription(sub: Omit<LocalSubscription, 'id' | 'subscribedDate' | 'status'> & Partial<Pick<LocalSubscription, 'status' | 'subscribedDate'>>) {
  const list = read();
  const existingIdx = list.findIndex(s => String(s.modelId) === String(sub.modelId));
  const now = new Date().toISOString();

  const record: LocalSubscription = {
    id: `local_${sub.modelId}_${Date.now()}`,
    modelId: sub.modelId,
    modelName: sub.modelName,
    developerName: sub.developerName,
    price: sub.price,
    billingCycle: sub.billingCycle || 'monthly',
    status: sub.status || 'active',
    subscribedDate: sub.subscribedDate || now,
    nextBilling: sub.nextBilling ?? null,
    category: sub.category,
    performance: sub.performance,
  };

  if (existingIdx >= 0) {
    list[existingIdx] = record;
  } else {
    list.push(record);
  }
  write(list);
  return record;
}

export function mergeSubscriptions(primary: any[], local: LocalSubscription[]) {
  // Merge by modelId; prefer primary (server) if present
  const byModel = new Map<string, any>();
  (primary || []).forEach(p => {
    const key = String(p.modelId ?? p.id ?? p.model?.id ?? '');
    if (key) byModel.set(key, p);
  });
  (local || []).forEach(l => {
    const key = String(l.modelId);
    if (!byModel.has(key)) {
      byModel.set(key, l);
    }
  });
  return Array.from(byModel.values());
}
```

Subscribe confirmation dialog

```tsx name=client/src/components/subscriptions/SubscribeConfirm.tsx
import { Dialog, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter } from '@/components/ui/dialog';
import { Button } from '@/components/ui/button';

type Props = {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  modelName: string;
  price: number;
  billingCycle?: 'monthly' | 'annually';
  onConfirm: () => void;
  isSubmitting?: boolean;
};

export default function SubscribeConfirm({
  open,
  onOpenChange,
  modelName,
  price,
  billingCycle = 'monthly',
  onConfirm,
  isSubmitting
}: Props) {
  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Subscribe to {modelName}</DialogTitle>
          <DialogDescription>
            Confirm your subscription. You will be charged ${price}/{billingCycle}.
          </DialogDescription>
        </DialogHeader>

        <div className="text-sm text-muted-foreground">
          - Cancel anytime from My Subscriptions
          <br />
          - Access the model immediately after subscribing
        </div>

        <DialogFooter>
          <Button variant="outline" onClick={() => onOpenChange(false)} disabled={isSubmitting}>
            Cancel
          </Button>
          <Button onClick={onConfirm} disabled={isSubmitting}>
            {isSubmitting ? 'Subscribing...' : 'Confirm'}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

Find where you have the source subscriptions array (often named subscriptions from useQuery or a mock). Merge:

```tsx name=client/src/pages/my-subscriptions.tsx
// After you obtain `subscriptions` (server/mocked)
const localSubs = getLocalSubscriptions();
const mergedSubscriptions = mergeSubscriptions(subscriptions || [], localSubs);

// Use mergedSubscriptions everywhere instead of `subscriptions`
const filteredSubscriptions = mergedSubscriptions.filter(sub => {
  if (activeTab === "all") return true;
  return sub.status === activeTab;
});

const totalMonthlySpend = mergedSubscriptions
  .filter(sub => sub.status === 'active' && sub.billingCycle === 'monthly')
  .reduce((total, sub) => total + (Number(sub.price) || 0), 0);

const totalAnnualSpend = mergedSubscriptions
  .filter(sub => sub.status === 'active' && sub.billingCycle === 'annually')
  .reduce((total, sub) => total + (Number(sub.price) || 0), 0);
```

Reflect subscriptions in Billing

Add a small card under the Overview tab to display active model subscriptions (merged with local).

1) At the top:

```tsx name=client/src/pages/billing.tsx
import { useEffect, useState } from 'react';
import { getLocalSubscriptions } from '@/lib/subscriptionsLocal';
```

2) Inside component:

```tsx name=client/src/pages/billing.tsx
const [activeModelSubs, setActiveModelSubs] = useState<{ modelName: string; price: number; billingCycle: string }[]>([]);

useEffect(() => {
  // If you later fetch server subscriptions, merge with local here.
  const locals = getLocalSubscriptions().filter(s => s.status === 'active');
  setActiveModelSubs(locals.map(s => ({ modelName: s.modelName, price: s.price, billingCycle: s.billingCycle })));
}, []);
```

3) In the Overview tab, under “Current Plan” card, add this card:

```tsx name=client/src/pages/billing.tsx

    <CardTitle>Active Model Subscriptions</CardTitle>
    <CardDescription>Your AI model subscriptions billed via GeFi</CardDescription>

    {activeModelSubs.length === 0 ? (
      <div className="text-sm text-muted-foreground">No active model subscriptions yet.</div>
    ) : (
      <div className="space-y-3">
        {activeModelSubs.map((s, idx) => (
          <div key={idx} className="flex items-center justify-between p-3 border rounded-lg">
            <div>
              <div className="font-medium">{s.modelName}</div>

```

What this delivers
- Clicking “Subscribe” opens a confirmation with the actual price.
- On confirm:
  - Calls POST /api/ai-models/:id/subscribe (existing route).
  - Adds a local record for immediate reflection in:
    - /my-subscriptions (merged with any server data)
    - /billing (Active Model Subscriptions section)
  - Invalidates relevant queries for when server persistence is added.
  - Optionally navigates to /my-subscriptions.

Notes
- This is safe to ship now and works even before server persistence is complete.
- When you later implement persistent subscriptions:
  - Have /api/user/subscriptions return the user’s real subscriptions.
  - The merge will prefer server data automatically.
- If you want the Subscribe button to handle Stripe Checkout flows, your existing subscribeMutation already redirects when data.checkoutUrl is present; the confirmation dialog runs before that as requested.
