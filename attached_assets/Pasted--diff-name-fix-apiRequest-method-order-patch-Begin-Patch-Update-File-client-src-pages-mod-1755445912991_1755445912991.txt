How this fixes the error
- The project's apiRequest helper expects apiRequest(method, url, ...). When the arguments are passed in the wrong order (url first, method second) fetch receives an invalid method string (e.g. "/api/ai-models/5") which causes the runtime error "Method is not a valid HTTP token."
- The patch corrects the order in ModelDetail (GET/POST) and updates the test to mock & assert the correct call signature.
