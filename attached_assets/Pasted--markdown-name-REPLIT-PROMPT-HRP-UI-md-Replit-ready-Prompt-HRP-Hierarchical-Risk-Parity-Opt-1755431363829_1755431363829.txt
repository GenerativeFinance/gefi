# Replit-ready Prompt — HRP (Hierarchical Risk Parity) Optimization Dashboard (React + Tailwind)

Goal
- Build a responsive, production-minded React + Tailwind UI for "Portfolio Optimization & HRP (AI-enhanced)" that balances quant insights (weights, risk decomposition, correlation) with executive clarity (allocation charts, performance scenarios).
- The prompt below is designed to be pasted into a Replit AI/assistant or used with a code generator to produce a working app scaffold + components, mock data, and clear integration points for a backend/ML service.

Tech stack (recommend)
- React (Vite or Create React App)
- Tailwind CSS
- Charts: react-apexcharts (main charts), d3-hierarchy + d3-cluster (dendrogram/HRP tree), react-heatmap-grid (correlation heatmap) or custom canvas
- CSV parsing: PapaParse
- File upload UI: react-dropzone (optional)
- State: React Context + hooks (or Zustand)
- Optional: Axios or fetch for API calls

Packages to install (example)
- react, react-dom
- tailwindcss, postcss, autoprefixer
- react-apexcharts, apexcharts

Functional Requirements (mapped to UI)
1) Left Sidebar — Input Panel (compact, collapsible)
- Data Sources:
  - CSV/Excel upload: Accept CSV with columns like ticker, weight, returns, volatility (sample CSV provided below).
  - API connectors: provide UI placeholders for Bloomberg / Yahoo / Quandl connectors (buttons + credential modal). These can call mock endpoints initially.
- Optimization Options:
  - Method selector: dropdown: Mean-Variance, Risk Parity, HRP, HRP + AI adjustment.
  - Constraints UI: modal or inline inputs: max weight, min weight, sector allocations, custom constraints (add/remove).
  - Risk tolerance slider: numeric slider with labels conservative (left) ↔ aggressive (right).
- AI Adjustment Controls:
  - Toggle: AI factor adjustments (on/off).
  - AI factors: checkboxes: macro risk, sentiment, ESG tilt.
  - Scenario selector: Base Case, Inflation Shock, Recession, Bull Market (multi-select or radio).
- Buttons:
  - Run Optimization (primary)
  - Reset / Load Example Data

2) Center Panel — Main Dashboard
- Top: Header with the portfolio name, quick stats (total AUM, # assets).
- Portfolio Allocation Visualization:
  - Sunburst (or Treemap) by asset / sector.
  - Pie chart: optimized HRP allocation vs original allocation (side-by-side).
- Correlation & Clustering:
  - Dendrogram: show HRP tree structure; interactive (hover reveals cluster members).
  - Correlation heatmap: click a cell to highlight assets in allocation charts.
- Performance Metrics:
  - Numeric cards: Expected Return, Volatility, Sharpe, VaR, CVaR.
- Scenario Simulation:
  - Multi-line chart: portfolio returns under selected scenarios.
  - Monte Carlo fan chart: show percentiles; allow horizon selection.

3) Right Sidebar — Insights Panel
- Risk Contribution Breakdown:
  - Table: Asset | Allocation % | Risk Contribution % | AI Adjustment ( +/-% )
  - Sortable and searchable.
- Factor Exposure View:
  - Horizontal bar chart: exposures (Market, Size, Momentum, ESG tilt, Macro).
- Explainability Layer:
  - AI-generated text block: "Why these allocations changed" and "Top drivers of allocation changes" (collapsible).
  - Buttons: "Show advanced math" toggles to reveal formulas and decomposition.

4) Export & Reporting
- Export as CSV / Excel / JSON (optimized weights + metadata).
- Download charts (PNG/PDF) — use chart library export options or html2canvas for screenshots.
- Generate AI-written Portfolio Report (saves as .md or PDF) — a server API will call LLM to produce text (placeholder local generator for now).

UX & Interactions
- Step-based workflow: Upload → Configure → Run → Inspect → Export.
- All charts sync on hover/selection. Example: hover an asset in the treemap highlights the row in the risk table and the heatmap.
- Mobile friendly: left/right sidebars collapse into drawers; center charts stack vertically.
- Accessibility: keyboard navigation, aria labels for major controls, colorblind-friendly palettes.
