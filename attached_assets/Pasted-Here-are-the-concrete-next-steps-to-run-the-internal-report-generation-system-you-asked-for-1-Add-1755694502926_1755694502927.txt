Here are the concrete next steps to run the internal report-generation system you asked for.

1) Add the new files
- Create these files exactly as provided in my previous message:
  - server/templates/reportTemplates.ts

  - server/routes/reports.ts

2) Install dependency
- From the repo root:
  - npm install puppeteer

3) Register the routes in the server
- In server/index.ts, import and register the new routes before setupVite is called (development) and after your other app routes are wired.

```typescript name=server/index.ts
// Add near other imports
import registerReports from "./routes/reports";
import registerStorageRoutes from "./routes/storage";

// Inside your bootstrap (before setupVite in development)
(async () => {
  const server = await registerRoutes(app);

  // Register the new APIs
  registerReports(app);
  registerStorageRoutes(app);

  // existing error handler remains...

  if (app.get("env") === "development") {
    await setupVite(app, server);
  } else {
    // If you use production mode locally, ensure static build is available
    serveStatic(app);
  }

  app.listen(PORT, () => log(`serving on port ${PORT}`));
})();
```

4) Restart the dev server
- Replit Run (or locally): NODE_ENV=development npx tsx server/index.ts
- The server should start as usual.

5) Quick test via API
- Generate a sample Risk Report and download it:

```bash
curl -s -X POST http://localhost:5000/api/reports/generate \
  -H "Content-Type: application/json" \
  -d '{
    "template":"risk",
    "input":{
      "title":"Risk Assessment - Equity Portfolio",
      "period":"Last 30 days",
      "generatedBy":"GeFi",
      "summary":"Comprehensive risk analysis across portfolio exposures.",
      "metrics":[
        {"label":"Total Reports","value":"6"},
        {"label":"Critical","value":"1"},
        {"label":"Portfolio VaR","value":"$3,052,000"}
      ],
      "sections":[
        {"heading":"Highlights","body":"• VaR +12.5% • 2 high risk items • Elevated liquidity stress."}
      ]
    }
  }'
```

- The response contains downloadUrl, e.g. /api/reports/<id>/download
- Open the download URL in a browser to verify the PDF.
- List files to see it in storage:
  - GET http://localhost:5000/api/storage/files

7) Storage UI verification
- Your Storage Management page can call GET /api/storage/files to display files. Generated PDFs will appear under type “Report” with a direct downloadUrl set for convenience.
- If your Storage page already lists files from the backend, this will start showing new report PDFs automatically.

Notes
- Puppeteer is launched with --no-sandbox to work in Replit by default.
- No extra env vars are required. The system writes to storage/reports and storage/reports/metadata, creating folders on demand.
