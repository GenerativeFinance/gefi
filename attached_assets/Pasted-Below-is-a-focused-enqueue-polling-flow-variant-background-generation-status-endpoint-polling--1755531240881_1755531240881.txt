Below is a focused enqueue/polling flow variant (background generation + status endpoint + polling + disabled Download until ready). This variant is the recommended approach for large reports: the client enqueues a job, polls a status endpoint, and only enables/downloads when the report status is "completed". The worker runs in background (BullMQ + Redis), creates the PDF (Puppeteer), stores metadata in a small JSON metadata store and writes the PDF to storage (or optionally uploads to S3 if S3 env is configured).

Drop these files into your repo, mount the router in your server, install the dependencies, start Redis and run the worker process.

Files to add / modify
- server/routes/reports.ts — POST /generate (enqueue), GET /:id/status, GET /:id/download
- server/workers/reportQueue.ts — BullMQ queue + worker
- server/models/reportStore.ts — simple JSON metadata store
- server/workers/reportGenerator.ts — worker job processor (renders HTML -> PDF, writes to storage, optional S3)
- client/src/utils/reportPoller.ts — client-side poller + download helper
- client/src/pages/investor/reports.tsx — small snippet showing how to enqueue/poll and disable Download until ready
- docs/REPORTS.md — quick run instructions

Notes
- This variant uses local storage by default (storage/reports). If you set S3_BUCKET + AWS credentials, the worker will upload the PDF to S3 and store a signed URL (15min) in the metadata.
- The client polls /api/reports/:id/status with exponential backoff. The Download button should be disabled while status !== completed.
- Ensure templates guard missing fields (fix user.profileImageUrl). See server/templates/standard-report.html in the repo and ensure using a safe guard (user = user || {} in renderer).

```typescript name=server/routes/reports.ts
import express from "express";
import { v4 as uuidv4 } from "uuid";
import reportQueue from "../workers/reportQueue";
import reportStore from "../models/reportStore";

const router = express.Router();

/**
 * POST /api/reports/generate
 * Body: { templateId?, reportType?, params? }
 * Response: { success: true, reportId, statusUrl }
 */
router.post("/generate", async (req, res) => {
  try {
    const user = (req as any).user || {}; // adapt to your auth middleware
    const { templateId, reportType = "custom", params = {} } = req.body || {};

    const reportId = uuidv4();
    const now = new Date().toISOString();

    const metadata = {
      id: reportId,
      ownerId: user.id || null,
      templateId: templateId || reportType,
      status: "pending",
      createdAt: now,
      updatedAt: now,
      progress: 0,
      error: null,
      pdfPath: null,
      s3Key: null,
      signedUrl: null
    };

    await reportStore.createReport(metadata);

    // enqueue job
    await reportQueue.enqueueReport({
      reportId,
      ownerId: metadata.ownerId,
      templateId: metadata.templateId,
      params,
    });

    return res.status(202).json({
      success: true,
      reportId,
      statusUrl: `/api/reports/${reportId}/status`,
      downloadUrl: `/api/reports/${reportId}/download`
    });
  } catch (err) {
    console.error("POST /api/reports/generate error:", err);
    return res.status(500).json({ success: false, error: String(err) });
  }
});

/**
 * GET /api/reports/:id/status
 * Response: { success: true, reportId, status, progress, downloadUrl?, error? }
 */
router.get("/:id/status", async (req, res) => {
  try {
    const { id } = req.params;
    const metadata = await reportStore.getReport(id);
    if (!metadata) return res.status(404).json({ success: false, error: "Report not found" });

    return res.status(200).json({
      success: true,
      reportId: id,
      status: metadata.status,
      progress: metadata.progress,
      downloadUrl: metadata.status === "completed" ? (metadata.signedUrl || `/api/reports/${id}/download`) : null,
      error: metadata.error || null
    });
  } catch (err) {
    console.error("GET /api/reports/:id/status error:", err);
    return res.status(500).json({ success: false, error: String(err) });
  }
});

/**
 * GET /api/reports/:id/download
 * If completed:
 *  - redirects to signed S3 URL (if uploaded), OR
 *  - streams local PDF file saved to storage/reports/report-<id>.pdf
 */
router.get("/:id/download", async (req, res) => {
  try {
    const { id } = req.params;
    const metadata = await reportStore.getReport(id);
    if (!metadata) return res.status(404).json({ success: false, error: "Report not found" });

    if (metadata.status !== "completed") {
      return res.status(202).json({ success: false, error: "Report not ready", status: metadata.status });
    }

    if (metadata.signedUrl) {
      return res.redirect(metadata.signedUrl);
    }

    if (metadata.pdfPath) {
      // send file
      return res.sendFile(metadata.pdfPath);
    }

    return res.status(500).json({ success: false, error: "No PDF available" });
  } catch (err) {
    console.error("GET /api/reports/:id/download error:", err);
    return res.status(500).json({ success: false, error: String(err) });
  }
});

export default router;
```

```typescript name=server/workers/reportQueue.ts
import { Queue, Worker, QueueScheduler } from "bullmq";
import IORedis from "ioredis";
import reportStore from "../models/reportStore";
import { processReportJob } from "./reportGenerator";

const redisUrl = process.env.REDIS_URL || "redis://127.0.0.1:6379";
const connection = new IORedis(redisUrl);

const queueName = "reports";
const queue = new Queue(queueName, { connection });
const scheduler = new QueueScheduler(queueName, { connection });

const worker = new Worker(
  queueName,
  async (job) => {
    const payload = job.data;
    const reportId = payload.reportId;
    try {
      await reportStore.updateReport(reportId, { status: "processing", progress: 5, updatedAt: new Date().toISOString() });

      const result = await processReportJob(payload, async (progress) => {
        await reportStore.updateReport(reportId, { progress, updatedAt: new Date().toISOString() }).catch(() => {});
      });

      if (result.success) {
        await reportStore.updateReport(reportId, {
          status: "completed",
          progress: 100,
          s3Key: result.s3Key || null,
          signedUrl: result.signedUrl || null,
          pdfPath: result.pdfPath || null,
          updatedAt: new Date().toISOString()
        });
      } else {
        await reportStore.updateReport(reportId, {
          status: "failed",
          error: result.error || "Unknown error",
          updatedAt: new Date().toISOString()
        });
      }
    } catch (err) {
      console.error("Worker job error:", err);
      await reportStore.updateReport(reportId, {
        status: "failed",
        error: String(err),
        updatedAt: new Date().toISOString()
      });
      throw err;
    }
  },
  { connection, concurrency: 2 }
);

async function enqueueReport(payload: any) {
  await queue.add("generate", payload, { attempts: 3, backoff: { type: "exponential", delay: 5000 } });
}

export default { enqueueReport, queue, worker, scheduler };
```

```typescript name=server/models/reportStore.ts
import fs from "fs/promises";
import path from "path";

const META_DIR = path.join(process.cwd(), "storage", "reports", "metadata");

async function ensureDir() {
  await fs.mkdir(META_DIR, { recursive: true });
}

async function metaPath(id: string) {
  await ensureDir();
  return path.join(META_DIR, `${id}.json`);
}

async function createReport(metadata: any) {
  const p = await metaPath(metadata.id);
  await fs.writeFile(p, JSON.stringify(metadata, null, 2), "utf8");
  return metadata;
}

async function updateReport(id: string, delta: any) {
  const p = await metaPath(id);
  try {
    const raw = await fs.readFile(p, "utf8");
    const data = JSON.parse(raw);
    const merged = { ...data, ...delta };
    await fs.writeFile(p, JSON.stringify(merged, null, 2), "utf8");
    return merged;
  } catch (err) {
    throw err;
  }
}

async function getReport(id: string) {
  const p = await metaPath(id);
  try {
    const raw = await fs.readFile(p, "utf8");
    return JSON.parse(raw);
  } catch (_err) {
    return null;
  }
}

export default { createReport, updateReport, getReport };
```

```typescript name=server/workers/reportGenerator.ts
import path from "path";
import fs from "fs/promises";
import puppeteer from "puppeteer";
import { uploadBufferToS3, getSignedUrlForKey } from "../services/s3"; // optional; create if using S3

const OUTPUT_DIR = path.join(process.cwd(), "storage", "reports");

type JobPayload = {
  reportId: string;
  templateId?: string;
  params?: any;
  ownerId?: string | null;
};

export async function processReportJob(payload: JobPayload, onProgress?: (percent: number) => void) {
  const reportId = payload.reportId;
  await fs.mkdir(OUTPUT_DIR, { recursive: true });

  try {
    const data = {
      reportName: payload.templateId || "standard-report",
      params: payload.params || {},
      user: (payload.params && payload.params.user) ? payload.params.user : {}, // guard user
      generatedAt: new Date().toISOString(),
    };

    // Load template HTML (simple renderer; adapt to your templating engine)
    const templatePath = path.join(process.cwd(), "server", "templates", `${data.reportName}.html`);
    const fallbackTemplate = path.join(process.cwd(), "server", "templates", "standard-report.html");
    const chosen = (await fs.stat(templatePath).catch(() => null)) ? templatePath : fallbackTemplate;
    let html = await fs.readFile(chosen, "utf8");

    // Minimal interpolation for a couple of fields; replace with your renderer (Handlebars/EJS) if present
    html = html.replace(/\{\{reportName\}\}/g, data.reportName);
    html = html.replace(/\{\{generatedAt\}\}/g, data.generatedAt);

    const tmpHtmlPath = path.join(OUTPUT_DIR, `report-${reportId}.html`);
    await fs.writeFile(tmpHtmlPath, html, "utf8");
    onProgress && onProgress(20);

    const browser = await puppeteer.launch({
      args: ["--no-sandbox", "--disable-setuid-sandbox", "--disable-dev-shm-usage"],
      headless: true,
    });

    const page = await browser.newPage();
    await page.goto(`file://${tmpHtmlPath}`, { waitUntil: "networkidle0", timeout: 120000 });

    const pdfBuffer = await page.pdf({
      format: "A4",
      printBackground: true,
      margin: { top: "20mm", right: "12mm", bottom: "20mm", left: "12mm" },
    });
    await browser.close();
    onProgress && onProgress(80);

    const pdfPath = path.join(OUTPUT_DIR, `report-${reportId}.pdf`);
    await fs.writeFile(pdfPath, pdfBuffer);

    let s3Key = null;
    let signedUrl = null;
    if (process.env.S3_BUCKET) {
      s3Key = `reports/${reportId}.pdf`;
      await uploadBufferToS3(s3Key, pdfBuffer, "application/pdf");
      signedUrl = await getSignedUrlForKey(s3Key, 900);
    }

    onProgress && onProgress(100);
    return { success: true, pdfPath, s3Key, signedUrl };
  } catch (err: any) {
    console.error("processReportJob error:", err);
    return { success: false, error: String(err) };
  }
}
```

```typescript name=client/src/utils/reportPoller.ts
// Client helper: enqueue + poll + download flow for reports
export async function enqueueReport(reportType: string, params: any = {}) {
  const res = await fetch("/api/reports/generate", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ reportType, params }),
  });
  if (!res.ok) {
    const body = await res.json().catch(() => ({}));
    throw new Error(body?.error || `Failed to enqueue report (${res.status})`);
  }
  return res.json();
}

export async function pollReportStatus(reportId: string, { signal, onProgress }:{ signal?:AbortSignal, onProgress?: (p:number)=>void } = {}, maxAttempts = 20) {
  const url = `/api/reports/${encodeURIComponent(reportId)}/status`;
  let attempt = 0;
  let delay = 1000;
  while (attempt < maxAttempts) {
    if (signal?.aborted) throw new Error("Aborted");
    try {
      const res = await fetch(url, { method: "GET", signal });
      if (!res.ok) {
        const body = await res.json().catch(()=>null);
        throw new Error(body?.error || `Status check failed ${res.status}`);
      }
      const json = await res.json();
      onProgress && onProgress(json.progress || 0);
      if (json.status === "completed") return json.downloadUrl || `/api/reports/${reportId}/download`;
      if (json.status === "failed") throw new Error(json.error || "Report generation failed");
    } catch (err) {
      console.warn("poll attempt failed:", err);
    }
    await new Promise((r) => setTimeout(r, delay));
    delay = Math.min(30000, Math.round(delay * 1.8));
    attempt++;
  }
  throw new Error("Report generation timed out");
}

export async function downloadFromUrl(url: string) {
  // try window.open first (signed GETs typically work)
  try {
    window.open(url, "_blank");
    return;
  } catch (err) {
    console.warn("window.open failed, falling back to fetch+blob", err);
  }

  const res = await fetch(url);
  if (!res.ok) throw new Error("Download failed");
  const blob = await res.blob();
  const blobUrl = window.URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = blobUrl;
  a.download = `report_${Date.now()}.pdf`;
  document.body.appendChild(a);
  a.click();
  a.remove();
  window.URL.revokeObjectURL(blobUrl);
}
```

````markdown name=docs/REPORTS.md
# Report generation (enqueue + polling variant)

This document describes the background generation flow and how to test it locally.

Required env vars
- REDIS_URL (e.g. redis://127.0.0.1:6379)
- Optionally for S3:
  - S3_BUCKET
  - AWS_REGION
  - AWS_ACCESS_KEY_ID
  - AWS_SECRET_ACCESS_KEY

Install additional server deps
- npm install --save bullmq ioredis puppeteer
- If using S3: npm install --save @aws-sdk/client-s3 @aws-sdk/s3-request-presigner

Start local Redis
- docker run -p 6379:6379 redis

Mount router
- In your server entry (e.g., server/app.ts or index.ts), mount:
  app.use("/api/reports", require("./routes/reports").default);

Start server
- npm run dev (or your dev start)

Start worker (separate process)
- NODE_ENV=development node dist/server/workers/reportQueue.js
  or run via ts-node for development:
- npx ts-node server/workers/reportQueue.ts

Flow
1. Client POST /api/reports/generate -> returns { reportId, statusUrl }
2. Client polls GET /api/reports/:id/status until status === "completed"
3. When completed, the status response includes downloadUrl (signed S3 URL if S3 configured) or the client can call GET /api/reports/:id/download to retrieve the file
4. Worker processes jobs in background and updates metadata in storage/reports/metadata/<reportId>.json

Troubleshooting
- If templates crash due to undefined fields (e.g. user.profileImageUrl), ensure renderer receives safe defaults (user = {}).
- Puppeteer needs font assets if you rely on custom fonts; make sure fonts are available to the headless browser.
- For production, run the worker under a process manager (pm2, systemd) and consider storing metadata in your DB instead of JSON files.
````
