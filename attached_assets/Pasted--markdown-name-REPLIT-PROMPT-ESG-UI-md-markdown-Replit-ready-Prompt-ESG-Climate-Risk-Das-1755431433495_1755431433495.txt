# Replit-ready Prompt — ESG & Climate Risk Dashboard (React + Tailwind)

Goal
- Build a responsive, executive-friendly React + Tailwind UI for "ESG & Climate Risk Models (AI Climate Risk Models)" that highlights sustainability insights, risk exposure, and portfolio alignment while allowing analysts to dive deeper.
- The prompt below is designed to be pasted into Replit AI (or used with a code generator) to produce a working app scaffold + components, mock data, and clear integration points for a backend/model service.

Defaults (used unless you request changes)
- Project: Vite + React + TypeScript + Tailwind CSS
- Charts & viz: react-apexcharts (charts) + d3 (custom visualizations)
- Map: react-leaflet + leaflet for climate heatmaps (avoids Mapbox API key for demo)
- CSV / Excel parsing: PapaParse + xlsx (sheetjs)
- File upload UI: react-dropzone
- State: React Context + hooks (or Zustand)
- HTTP: axios
- Optional: deck.gl or Mapbox integration notes for high-res spatial visualizations (left as optional)

Packages to install (example)
- react, react-dom, typescript, vite
- tailwindcss, postcss, autoprefixer
- react-apexcharts, apexcharts
- react-leaflet, leaflet
- d3
- papaparse
- xlsx
- react-dropzone
- axios
- pdfjs-dist (if you want PDF report previews)
- html2canvas (for chart export)

Functional Requirements (mapped to UI)

1) Left Sidebar — Input Panel (collapsible, 280px)
- Data Sources:
  - Upload ESG reports / climate datasets (CSV, Excel, JSON). Provide sample templates and "Load Example Dataset".
  - API connector placeholders for MSCI, Sustainalytics, CDP, satellite feeds (buttons open credential modal; call mock endpoints initially).
- Model Selection:
  - Dropdown: ESG Scoring Model (NLP, rule-based, hybrid), Climate Risk Model (physical, transition, carbon footprint).
- Portfolio Input:
  - Upload holdings (ISIN, ticker, company, weight).
  - Filters: sector, region, market cap.
- Controls:
  - Run Analysis (primary)
  - Scenario selector (1.5°C, 2°C, Business as Usual)
  - Date range picker for time-based analysis
  - Toggle: show/hide alternative data overlays (satellite trends, social sentiment)

2) Center Panel — Main Dashboard (1fr)
- Top header: portfolio name, AUM, # holdings, last update, quick export button
- Portfolio ESG Score Overview:
  - Gauge or rating (AAA → CCC) component plus weighted average ESG score and delta vs benchmark
- Climate Risk Heatmap:
  - Global/regional interactive map (react-leaflet) showing portfolio exposure to physical & transition risks
  - Hover / click shows company exposures & scenario impact
- Alternative Data Insights:
  - Satellite trend card (placeholder image / time-series)
  - Social sentiment sparkline & news feed summary
- Scenario Stress Testing:
  - Cards showing scenario outputs: portfolio loss %, % companies above threshold, carbon price impact
  - Time series / area charts for scenario projections

3) Right Sidebar — Insights Panel (360px)
- Company-Level Breakdown:
  - Table: Company | Ticker | ESG Score | Carbon Intensity | % Weight | Risk Tier | Action (drill-in)
  - Rows expandable to show mini-chart and notes
- Top ESG Risk Drivers:
  - Bar chart: contribution to portfolio risk (carbon emissions, water usage, governance controversies)
- Sector & Geographic Exposure:
  - Pie charts: weight by sector, weight by region, risk-tier distribution
- Regulatory Compliance View:
  - EU Taxonomy alignment meter, SFDR flags, checklist for disclosures
- Explainability / AI Notes:
  - Collapsible AI-written rationale: "Top green leaders" and "Top red flags" (placeholder LLM or static text for demo)

4) Export & Reporting
- Export portfolio ESG & climate risk as CSV / Excel / JSON
- Download allocation / map charts as PNG/PDF (html2canvas or library export)
- Generate AI-written Executive ESG Report: summary + recommended actions (hook to LLM API via backend; mock text in demo)

- Holdings CSV header:
  - isin,ticker,company,sector,region,current_weight
- ESG scores CSV header:

    }

- For satellite-derived insights include placeholder images or WMS endpoints in the mock.
