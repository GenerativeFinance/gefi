Notes / rationale
- The root cause for /model/5, /model/6, /model/7, /model/8 rendering as "Model Not Found" was that ModelDetail previously only attempted to read route params for the "/marketplace/:id" path. The app registers the page under "/model/:id" (and various other legacy paths), so params were undefined.
- The updated component:
  - Tries both "/model/:id" and "/marketplace/:id" via useRoute.
  - Falls back to parsing window.location.pathname to extract an ID if both useRoute checks return nothing.
  - Uses the resolved idParam to enable and key the React Query that fetches /api/ai-models/:id.
  - Adds small defensive guards so users see a clear message if there's no id or if the model is not found.
